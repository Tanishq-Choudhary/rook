limitations
- Fixtures are generated from nine change recipes over four invented SDKs. They are small single module Maven projects, not real customer repositories.
- Only Java SDK changes read from compiled jars are covered. OpenAPI changes are not part of this set.
- Verification runs offline Maven on the host with the local process runner. The isolated Docker path is tested separately and is not used for these numbers.
- The llm-only and agent rows come from one run each of a single model. They say little about other models, and another run can differ. The agent and llm-only prompts include the new SDK API for the types involved.
